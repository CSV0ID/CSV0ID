## 🚀 Projects

### [CS-AI](https://wadia-ai.vercel.app)
Full-stack AI chat platform with Google Sign-In, multi-model support (Gemini, NVIDIA Nemotron, OpenRouter), per-user token quotas enforced server-side, SSE streaming, Firestore-backed chat history, file attachments, and a role-based admin panel. Rate limited via Upstash Redis at 20 req/min per IP.

`JavaScript` `Firebase` `Vercel` `Gemini API` `OpenRouter` `Firestore`

---

### [Notes AI](https://wadia-panel-ai.vercel.app)
AI-powered study notes generator from any topic, pasted text, or uploaded PDF using Google Gemini 2.5 Pro. Four note styles — Structured, Bullet Points, Cornell Method, Mind Map. One-click PDF and Markdown export, zero backend.

`JavaScript` `Gemini 2.5 Pro` `jsPDF` `Vercel`

---

### Student Data Administration System
Java desktop app packaged as a signed Windows EXE. BCrypt login, role-based access control, live search across name/class/roll/mobile, full CRUD, admin panel for user management and class-level restrictions. Built and validated against 150+ real student records.

`Java` `AWT/Swing` `MySQL` `BCrypt` `Launch4j`

---

### CS MART
Amazon-inspired multi-page e-commerce frontend — product listings, discount badges, registration form with HTML5 validation. Built from scratch, no frameworks.

`HTML` `CSS`
